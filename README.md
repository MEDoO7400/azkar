# حصن المسلم

تطبيق ويب عربي متجاوب للأذكار اليومية، المسبحة الإلكترونية، والمصحف الشريف. المشروع مبني بملفات ويب ثابتة دون إعداد build أو مفاتيح API، ويمكن نشره مباشرة على Vercel.

## تشغيل محلي

افتح `index.html` في المتصفح لمعاينة التطبيق. لاختبار تثبيت التطبيق وميزة العمل دون اتصال، شغّل خادمًا محليًا عبر HTTPS أو localhost، مثل:

```bash
npx serve .
```

ثم افتح العنوان الذي يظهر في الطرفية. فهرس المصحف ونص السور يحتاجان إلى اتصال بالإنترنت؛ الأذكار والعداد والمفضلة تعمل دون اتصال بعد تحميل التطبيق مرة واحدة.

## النشر على Vercel

1. استورد المستودع `MEDoO7400/azkar` في Vercel.
2. اختر **Other** كإطار عمل إذا طُلب ذلك.
3. اترك **Build Command** و **Output Directory** فارغين؛ جذر المستودع هو موقع الملفات الثابتة.
4. اضغط **Deploy**. ملف `vercel.json` يضيف ترويسات أمان أساسية.

كل تحديث إلى الفرع `main` سيُعاد نشره تلقائيًا إذا كان Git مربوطًا بمشروع Vercel.

## المزايا

- واجهة RTL عربية متجاوبة مع الوضع الفاتح والداكن.
- أقسام الأذكار والبحث والعدادات والمفضلة، مع حفظ محلي للتقدم.
- مسبحة إلكترونية مع اهتزاز اختياري.
- فهرس السور وقراءة نص القرآن من خدمة AlQuran Cloud، مع البحث وتغيير حجم الخط.
- تطبيق PWA قابل للتثبيت؛ يحفظ واجهة التطبيق لتعمل دون اتصال بعد أول زيارة. المصحف يتطلب الإنترنت.
- تصدير نسخة احتياطية من بيانات المستخدم بصيغة JSON.

## ملاحظات

- لا توجد قاعدة بيانات أو حسابات مستخدمين؛ البيانات محفوظة في `localStorage` على الجهاز والمتصفح الحاليين.
- نص القرآن يُحمّل من واجهة AlQuran Cloud، لذلك تتطلب ميزة المصحف اتصالًا بالإنترنت وتوافر الخدمة.
- نصوص الأذكار وأعداد تكرارها تحتاج إلى مراجعة مرجعية قبل اعتمادها للنشر. التطبيق أداة تذكير وليس مصدرًا للإفتاء.
